# Varuna – Datenschutz / Privacy Policy

Stand / Last updated: 24.11.2026

## Deutsch

Varuna ist eine persönliche App für den Eigengebrauch des Betreibers. Sie läuft lokal auf dem Gerät des Betreibers.

- Nach ausdrücklicher Zustimmung (Google OAuth) greift Varuna auf Daten des eigenen Google-Kontos des Betreibers zu: Kalender, Aufgaben, E-Mail, Drive-Dateien.
- Die Daten werden nur lokal auf dem Gerät verarbeitet. Zum Austausch von Einstellungen und Rechercheergebnissen nutzt Varuna einzelne Ordner im Google Drive des Betreibers.
- Es erfolgt keine Weitergabe an Dritte, kein Verkauf, keine Werbung und kein Training von KI-Modellen mit diesen Daten.
- Die Nutzung von Google-Daten folgt der Google API Services User Data Policy, einschließlich der Limited-Use-Anforderungen.
- Der Zugriff kann jederzeit unter https://myaccount.google.com/permissions widerrufen werden.
- Kontakt: über das GitHub-Profil https://github.com/rosneh

## English

Varuna is a personal app for the operator's own use and runs locally on the operator's device.

- With explicit consent (Google OAuth), Varuna accesses data in the operator's own Google account: calendar, tasks, email and Drive files.
- Data is processed locally on the device. Varuna uses individual folders in the operator's Google Drive to exchange settings and research results.
- Data is not shared with third parties, not sold, not used for advertising and not used to train AI models.
- Use of Google user data adheres to the Google API Services User Data Policy, including the Limited Use requirements.
- Access can be revoked at any time at https://myaccount.google.com/permissions
- Contact: via the GitHub profile https://github.com/rosneh
